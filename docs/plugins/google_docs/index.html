Google Docs Plugin (googleDocs)

The Google Docs plugin connects workflows with the Google Docs REST API (https://docs.googleapis.com/v1/documents). It supports both appending generated text entries to the end of an existing Google Document and reading complete plain-text contents from a document for downstream processing (such as feeding document text into an LLM prompt).

Plugin Overview

Property Value
Plugin Label Google Docs
Step Type (type) googleDocs
Variable ID Prefix google_docs (e.g., google_docs_1, google_docs_2)
Group / Category Google
Authentication OAuth2 Bearer Token (chrome.identity.getAuthToken)
API Endpoint https://docs.googleapis.com/v1/documents/{documentId}
https://docs.googleapis.com/v1/documents/{documentId}:batchUpdate

Configuration Fields

Field Key (config.*) Form Label Type Required Description & Token Examples
action Action select ('append' | 'read') Yes Specifies whether to append text ('append') or extract existing document text ('read'). Default: 'append'.
documentId Google Document ID string Yes Unique identifier extracted from Google Docs URL (docs.google.com/document/d/[ID]/edit). Supports tokens (e.g., 1aBc... or {{globals.google_doc_id}}).
textTemplate Text to Append string Yes (when action: 'append') Template string appended to the end of the document body. Disabled when action: 'read'. Default: Document entry generated by AI:\n{{llm_1}}\n\n.

Template Tokens & State Output

Available Input Tokens

documentId and textTemplate accept dynamic token variables

Output State

Depending on the selected action, the plugin yields the following state variables:

  • For Read Action (action: 'read'):

    • {{google_docs_1.status}}: "success"
    • {{google_docs_1.documentId}}: Target document ID.
    • {{google_docs_1.title}}: Document title retrieved from Google Docs API.
    • {{google_docs_1.text}}: Full plain text extracted recursively from document paragraphs and tables.
    • {{google_docs_1.revisionId}}: Current document revision ID.

  • For Append Action (action: 'append'):

    • {{google_docs_1.status}}: "success"
    • {{google_docs_1.documentId}}: Target document ID.
    • {{google_docs_1.appendedTextLength}}: Character count of inserted text.
    • {{google_docs_1.replies}}: Array of batch update API response objects.

Sidebar UI Actions

  • View Doc: Renders an action button in the sidebar panel. Clicking it opens https://docs.google.com/document/d/{resolvedDocumentId}/edit in a new browser tab.

Example Workflow Configurations

Example 1: Read Prompt from Google Doc and Feed to LLM

{
	"id": "google_docs_1",
	"type": "googleDocs",
	"config": {
		"action": "read",
		"documentId": "{{globals.google_doc_id}}"
	}
}

Example 2: Append Web Snippet to Google Doc

{
	"id": "google_docs_1",
	"type": "googleDocs",
	"config": {
		"action": "append",
		"documentId": "{{globals.google_doc_id}}",
		"textTemplate": "### {{extract_1.title}}\nURL: {{url.href}}\n\nSelection:\n{{extract_1.selection}}\n\n"
	}
}
