Microsoft Word (microsoftWord)

The Microsoft Word plugin reads text from a Word document or appends templated text to an existing document through Microsoft Graph. It supports documents stored in OneDrive or SharePoint.

Plugin Overview

Property Value
Plugin Label Microsoft Word
Step Type (type) microsoftWord
Variable ID Prefix ms_word (e.g., ms_word_1, ms_word_2)
Group / Category Microsoft
Authentication Microsoft OAuth 2.0; uses global ms_client_id and optional ms_tenant_id (defaults to common)

Configuration Fields

Field Key (config.*) Form Label Type Required Description & Token Examples
action Action select No (defaults to append) Choose Append Text (append) or Get Document Content (read).
documentId OneDrive File ID / Document ID text Yes OneDrive or SharePoint document item ID. Supports tokens such as {{globals.word_document_id}}.
textTemplate Text to Append textarea Yes for append Text appended to the document; defaults to a template containing {{llm_1}}. Supports workflow tokens. Hidden and disabled in read mode.

Template Tokens & State Output

Available Input Tokens

The form exposes token insertion for OneDrive File ID / Document ID and Text to Append. For example, use {{globals.word_document_id}} for the document ID or {{llm_1}} in the appended text.

Output State

For Get Document Content, the step returns:

  • {{ms_word_1.status}}: success.
  • {{ms_word_1.documentId}}: Configured document ID.
  • {{ms_word_1.text}}: Document content returned by Microsoft Graph as text.

For Append Text, the step returns:

  • {{ms_word_1.status}}: success.
  • {{ms_word_1.documentId}}: Configured document ID.
  • {{ms_word_1.appendedTextLength}}: Length of the appended template text.
  • {{ms_word_1.result}}: Parsed response from Microsoft Graph, or an empty object if the response body is not valid JSON.

Sidebar UI Actions

  • View Doc: Opens the Word document in OneDrive when the configured document ID resolves without an unresolved template token.

Example Workflow Configuration (JSON)

{
	"id": "ms_word_1",
	"type": "microsoftWord",
	"config": {
		"action": "append",
		"documentId": "{{globals.word_document_id}}",
		"textTemplate": "Document entry generated by AI:\n{{llm_1}}\n\n"
	}
}
