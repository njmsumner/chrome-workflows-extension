Integration Steps

API/Webhook

api - Executes an HTTP request to an API endpoint or webhooks

OpenAI/LLM

llm - Send a prompt to an OpenAI-compatible API and return the completion text

Trello Create Card

trello_card - Creates a new card on a Trello board list.

Confluence Page

confluence - Updates Confluence page via the REST API

Gmail

gmail - Sends emails or saves drafts to Gmail.

Google Docs

google_docs - Append text to or reads content from a Google Doc

Google Sheets

google_sheets - Append a row to or reads content from a Google Sheet

HubSpot Blog Post

hubspot - Update HubSpot CMS blog posts via the CMS API

Jira Comment

jira - Adds a comment to the Jira issue.

Jira Create Issue

jira_issue - Creates a new issue in Jira (e.g. Task, Bug, Story).

Microsoft Excel

ms_excel - Append rows to an Excel table/worksheet and retrieve cell/range content.

Microsoft Outlook Email

ms_email - Sends an email or saves a draft using Microsoft Outlook.

Microsoft Teams

ms_teams - Send messages to Microsoft Teams.

Microsoft Word

ms_word - Append or read content from a Microsoft Word document.

Slack Notification

slack - Sends webhook messages to Slack channels
