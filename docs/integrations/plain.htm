AI Workflows Chrome Extension

Integration Steps

The integrations listed below are built-in to the extension and have their own UI for editing steps.

API/Webhook

Executes an HTTP request to an API endpoint or webhooks (api)

OpenAI/LLM

Send a prompt to an OpenAI-compatible API and return the completion text (openai)

Trello Create Card

Creates a new card on a Trello board list. (trello_card)

Confluence Page

Updates Confluence page via the REST API (confluence)

Gmail

Sends emails or saves drafts to Gmail. (gmail)

Google Docs

Append text to or reads content from a Google Doc (google_docs)

Google Sheets

Append a row to or reads content from a Google Sheet (google_sheets)

HubSpot Blog Post

Update HubSpot CMS blog posts via the CMS API (hubspot)

Jira Comment

Adds a comment to the Jira issue. (jira_comment)

Jira Create Issue

Creates a new issue in Jira (e.g. Task, Bug, Story). (jira_issue)

Microsoft Excel

Append rows to an Excel table/worksheet and retrieve cell/range content. (ms_excel)

Microsoft Outlook Email

Sends an email or saves a draft using Microsoft Outlook. (ms_email)

Microsoft Teams

Send messages to Microsoft Teams. (ms_teams)

Microsoft Word

Append or read content from a Microsoft Word document. (ms_word)

Slack Notification

Sends webhook messages to Slack channels (slack)
